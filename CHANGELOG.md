# Skin asset version history

The `skins` version tracks only the publicly shared pictures, RGB565 skin data, coordinate maps and documentation. It does not version or publish the radio firmware. Later changes will get a new entry here; fixes to existing assets increment the patch number, new skin features the minor number.

## 0.1.0-preview — 2026-10-02

- Initial public Winamp-inspired 320 × 240 player/EQ and playlist assets, plus 320 × 213 cassette asset.
- Added RGB565LE data, coordinate maps, visible README previews and a conversion helper.
- EQ curve is a visual rock-style preview; actual audio EQ is off. V118 physical screen testing and a stock-yoRadio display adapter remain pending.

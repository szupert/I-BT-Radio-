# LIGHT menütérkép · R471

![R471 menürendszer és kezelési útvonalak](../images/light-r471/menu-map.png)

| Főmenü csempéje | Mit nyit meg? |
|---|---|
| Rádió | Lejátszó, adóváltás, lejátszásvezérlés és forrásválasztás |
| Ébresztőóra | Óranézet, érintésre óravezérlés és az ébresztések beállítása |
| Időjárás | Az időjárás kijelzése a beállított helyhez |
| Relaxáció | Hang, Fény, Kombinált mód és programválasztás |
| Beállítások | Az alábbi csoportok a kijelző sorrendjében |

1. Wi-Fi
2. Kijelző
3. Hang
4. Bluetooth
5. Kezelés
6. Óra és ébresztő
7. Óra időzítése
8. Tárhely és SD
9. Rendszer
10. Szerviz · jelgenerátor

**Borítóletöltő:** Beállítások → Kijelző → Borítókép és VU → Borítókép beállításai → Borítóletöltő.

**Óra időzítése:** a közvetlen beállítás és az Óra és ébresztő almenü azonos időzítőt nyit meg. Visszalépéskor a megnyitó menübe térsz vissza.

**Borító és VU:** Beállítások → Kijelző → Borítókép és VU. Ugyanitt, a Kijelző menüben állítható a fényerő, a tájolás, a betűméret és az animáció.

**Akadozó adás:** Beállítások → Hang → Hangpuffer. Az adatpuffer és az újratöltések száma segít összehasonlítani két adót.

**Érintéskalibrálás:** Beállítások → Kezelés → Érintés. Az időzített óranézet a Beállítások → Óra időzítése sorból érhető el.

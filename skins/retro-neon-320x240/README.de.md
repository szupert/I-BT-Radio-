# retro-neon-320x240

Statischer Hintergrund mit 320×240 Pixeln, mit den RGB565-Daten der R83-Firmware verglichen. Texte, Cover und Bedienelemente werden zur Laufzeit gezeichnet. Kein Gerätefoto und keine vollständige Menüansicht. Auswahl in der Entwicklungsfirmware unter Anzeige → Oberfläche; die Version des öffentlichen Installers separat prüfen. Physische SMALL-Anzeige-/Touch-Prüfung: NOT_RUN.
